# Q7 空气竖琴（10 分）

**一句话**：超声波分 7 个区间对应 Do~Si，手越近音调越高，2~40cm 外静音。

## 引脚 / 接线速查

| 功能 | 真板引脚 |
|---|---|
| HC-SR04 TRIG | **PB6** |
| HC-SR04 ECHO | **PB7** ⚠️5V 需分压 |
| 无源蜂鸣器 | **PB9**（TIM4_CH4, AF2） |
| 调试串口 | PA9=TX / PA10=RX（AF7, 115200） |

> 仿真版：距离写进 0x2001FF00（mm），频率写回 0x2001FF04（Hz）。

## 核心逻辑伪代码

```
NOTE_FREQ = {523, 587, 659, 698, 784, 880, 988}   # C5 大调 Do~Si

cm_to_freq(cm):
    if cm < 2 or cm > 40: return 0                 # 静音
    note = (40 - cm) * 7 / 38                       # 0~6，反向映射
    if note > 6: note = 6
    return NOTE_FREQ[note]

main():
    循环:
        mm = 测距()                                 # 真板: ECHO高电平µs / 58
        f = cm_to_freq(mm / 10)
        if f == 0: 停 PWM
        else: TIM4 PWM 周期 = 1000000 / f, 占空比 50%
```

## 关键常量

| 项 | 值 |
|---|---|
| 量程 | 2~40cm，7 个区间（每区间 ≈ 5.4cm） |
| 音阶 | C5 大调：**523 / 587 / 659 / 698 / 784 / 880 / 988 Hz** |
| 映射 | `note = (40 - d) * 7 / 38`（d=40→Do，d=2→Si） |
| 换算 | `距离cm = ECHO高电平时间µs / 58` |
| 静音 | CCR = 0（停 PWM，不是发最低音） |

## 高频追问 + 一句话答法

- **为什么用无源蜂鸣器？** → 有源音高固定做不出音阶。无源没振荡源，我给它什么频率的方波它就发什么音。
- **改频率是改占空比吗？** → **不是，改周期（ARR）**。频率 = 1/周期，占空比保持 50% 不变，波形形状不变只改快慢。
- **这 7 个频率怎么来的？** → C 大调音阶 C5~B5，按十二平均律算，相邻比 2^(1/12)≈1.0595，**不是等差必须查表**。
- **区间怎么分的？** → `note=(40-d)*7/38`，量程改只要改常数逻辑不动。40cm→最低音，2cm→最高音，所以映射是反向的。
- **超量程为什么静音？** → 超范围发最低音的话分不清是 40cm 还是 1m。静音最诚实，也自然：远了没声，靠近才有。
- **会不会跳音？** → 会，手一动距离就变。加低通滤波或区间迟滞能解决，我这题为响应快没加。

## 被问住就说

> ⚠️ 仿真版**没有真的驱动 HC-SR04**（距离是脚本喂的、频率是写出去的），验证的是分区和音阶映射逻辑。
> ⚠️ **ECHO 是 5V 输出，必须分压再接 PB7**，很多模块的 ECHO 是 5V CMOS。
> ⚠️ 真板别忘了 HC-SR04 最短测量周期（手册建议 60ms，我真板版取 50ms）。

# Q4 电机风扇（10 分 · TB6612）

**一句话**：TB6612 驱动直流电机带风扇，两个独立按键分别升挡、降挡。

## 引脚 / 接线速查

| 功能 | 真板引脚 | 仿真版 |
|---|---|---|
| PWMA（速度） | PA0（**TIM2_CH1**, AF1） | mailbox（0x2001FF00） |
| AIN1（方向） | PA1 | PE0 |
| AIN2（方向） | PA2 | PE1 |
| STBY（使能） | PA3 | PE2 |
| 按键 加/减 | PB0 / PB1（上拉低有效） | PA0 / PA1（高有效） |

## 核心逻辑伪代码

```
DUTY_TBL = {0, 300, 600, 1000}      # 满刻度 1000

apply_gear(g):
    STBY = 1                       # 必须先拉高，否则芯片在待机
    if g == 0: AIN1=0, AIN2=0      # 00 = 滑行停车
    else:     AIN1=1, AIN2=0      # 10 = 正转
    PWM_DUTY = DUTY_TBL[g]         # 真板：写 TIM2->CCR1

main():
    gear = 0; apply_gear(0)
    循环:
        cur = 读按键
        pressed = cur & ~prev      # 上升沿
        if pressed & UP   and gear < 3: gear++
        if pressed & DOWN and gear > 0: gear--
        apply_gear(gear)
        prev = cur
```

## 关键常量

| 项 | 值 |
|---|---|
| 挡位 | 0~3（0 = 停） |
| DUTY_TBL | `{0, 300, 600, 1000}` |
| 方向编码 | `10`正转 `01`反转 `00`滑行 `11`刹车 |
| PWM 频率 | **20kHz**（周期 20000µs） |

## 高频追问 + 一句话答法

- **TB6612 怎么控方向和速度？** → AIN1/AIN2 两个 GPIO 组合出四种状态管方向，PWMA 接定时器 PWM 占空比管速度，STBY 是总使能。三者独立。
- **0 挡为什么用 00（滑行）不用 11（刹车）？** → 刹车是把电机两端短接急停，电流冲击大容易触发过流保护；滑行断开驱动自然减速，对电机和机械更温和。
- **PWM 频率多少？为什么？** → 20kHz（周期 20000µs）。定这么高是因为**高过听觉上限**，电机不会发出可闻的啸叫；周期取 20ms 也让"占空比"正好等于电流的导通比例，好算好解释。
- **挡位为什么查表不直接乘？** → 因为每档手感可以自由设计，"3 挡 = 100% 全力"这个意图查表一眼看得出来。
- **转不起来怎么排查？** → ①电源 ②**STBY 是不是高（第一嫌疑）** ③方向脚 ④示波器看 PWMA 有没有波形 ⑤占空比是不是算成 0 ⑥芯片是否过热。

## 被问住就说

> ⚠️ 仿真版主循环没有延时，`apply_gear` 会被反复调用；真板上有 PWM 天然有节流，不存在这问题。别在老师面前说"我在空转"，就说"仿真里主循环全速跑验证映射关系，真板直接写 CCR"。

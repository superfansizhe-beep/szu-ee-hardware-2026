# Q2 流水灯（10 分 · 必须用外部中断）

**一句话**：四个 LED 流水灯默认 2Hz，按键1 换方向，按键2 频率 2→1→0.5Hz 循环，必须用 EXTI。

## 引脚 / 接线速查

| 功能 | 真板引脚 | 仿真版 |
|---|---|---|
| LED1~4 | PD12/13/14/15（TIM4_CH1~4） | PD12~15 |
| 按键1（方向） | PB0 → **EXTI0 → IRQ6** | PA0 → EXTI0 |
| 按键2（频率） | PB1 → **EXTI1 → IRQ7** | PA1 → EXTI1 |

> 真板上拉低有效 → **配下降沿**（仿真版是上升沿）。别讲反。

## 核心逻辑伪代码

```
初始化: ① SYSCFG_EXTICR1: EXTI0→口A, EXTI1→口A（编码 0）
        ② EXTI_IMR  |= bit0|bit1          不屏蔽
        ③ EXTI_FTSR |= ...                真板选下降沿
        ④ NVIC_ISER0 = bit6 | bit7        使能 IRQ6/IRQ7

ISR(EXTI0): if(PR & bit0){ PR = bit0; direction ^= 1; }
ISR(EXTI1): if(PR & bit1){ PR = bit1; freq_idx = (freq_idx+1)%3; }

主循环:
    全灭; 亮 pos
    pos = direction ? (pos+3)%4 : (pos+1)%4
    delay(period[freq_idx])
```

## 关键常量

| 项 | 值 |
|---|---|
| period[] | `{400000, 800000, 1600000}`（2Hz/1Hz/0.5Hz 档） |
| 线号 → IRQ | EXTI0→6, EXTI1→7, EXTI5_9→23, EXTI10_15→40, TIM6_DAC→**54** |
| 向量表下标 | = IRQ + 16（EXTI0 在第 **22** 项） |

## 高频追问 + 一句话答法

- **为什么必须中断不用轮询？** → 题目写明了；而且中断在按下瞬间直接打断 CPU，主循环正在点灯也能立刻响应，不会漏掉短按。
- **EXTI 要配哪几步？** → 四步：SYSCFG 指端口、IMR 不屏蔽、RTSR/FTSR 选边沿、NVIC 使能。**漏 SYSCFG 中断永远不来**。
- **EXTI0 是几号中断？** → 三个号分清：EXTI 线号 0、**IRQ 号 6**、**向量表下标 22**。
- **ISR 里怎么清标志？** → `EXTI_PR = (1<<line)`，**写 1 清、写 0 没用**。不清就退出立刻再进来，死在中断里。
- **变量为什么加 volatile？** → direction/freq_idx 是中断写主循环读，不加 volatile 编译器可能缓存读值，永远读到旧值。

## 被问住就说

> ⚠️ **"2Hz" 的口径**：我按"每秒跳 2 次"实现（每步 0.5s，整圈 2s）。如果老师认为该按"整圈 2 次/秒"，把延时除以 4 就行，改一个数组的事。
> ⚠️ **真板按键抖动我没在 ISR 里消抖**——仿真里是理想沿。真板一次按下可能触发多次，ISR 要加 20ms 时间窗。这点我承认是仿真没覆盖到。

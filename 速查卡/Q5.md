# Q5 舵机（10 分）

**一句话**：电位器接 ADC 控制 SG90 舵机，旋钮从 0° 到 180° 连续平滑变化。

## 引脚 / 接线速查

| 功能 | 真板引脚 |
|---|---|
| SG90 信号 | **PB6**（TIM4_CH1, **AF2**） |
| 电位器中点 | **PA0**（ADC1_IN0） |
| 调试串口 | PA9=TX / PA10=RX（AF7, 115200） |

> 仿真版：目标角度由脚本喂进 0x2001FF00，算出的脉宽写回 0x2001FF04。

## 核心逻辑伪代码

```
deg_to_pulse(deg):
    if deg > 180: deg = 180        # 钳位，防顶机械限位
    return 500 + deg * 2000 / 180

main():
    TIM4 PWM: 周期 20000µs (20ms), 预装载 ON
    CCR = deg_to_pulse(0)           # 上电先给安全值
    循环:
        adc = adc_read_avg(PA0, 16) # 16 次平均去抖
        deg = adc * 180 / 4095      # 12bit → 角度
        CCR = deg_to_pulse(deg)     # 真板输出
```

## 关键常量

| 项 | 值 |
|---|---|
| SG90 脉宽 | **500µs@0° / 1500µs@90° / 2500µs@180°** |
| 公式 | `pulse_us = 500 + deg * 2000 / 180`（≈11.11 µs/度） |
| PWM 周期 | 20ms = 50Hz（ARR = 19999，1µs 一计数） |
| PSC | 83（84MHz ÷ 84 = 1MHz） |

## 高频追问 + 一句话答法

- **SG90 怎么控角度？** → 周期固定 20ms，高电平多宽代表多少角度：500µs=0°、1500µs=90°、2500µs=180°，中间线性。所以改 CCR 就是改角度。
- **⚠️ 定时器时钟为什么要 ×2？** → APB 分频≠1 时该总线定时器自动 ×2。APB1 分频 4 → PCLK1 42MHz 但 **TIM2~7 实际 84MHz**。忘了乘 2 脉宽差一倍。
- **电位器怎么接？** → 可变电阻接成分压器，上 3.3V、下地、中间抽头接 ADC。旋钮改变分压比，输出 0~3.3V 线性变化。
- **读数会跳吗？** → 会，量化误差+电源噪声+接触噪声能跳几十 LSB，映射到角度就是几度抖动。取 16 次平均，代价几十微秒。
- **为什么开预装载？** → 不开的话改 CCR 可能在周期中间生效，输出一个异常窄脉冲，舵机就是"猛抽一下"。

## 被问住就说

> ⚠️ **SG90 的实际脉宽余量我没把握**——不同批次机械限位不一样，2500µs 可能顶死。现场发现抖就把上限收到 **2400µs**。被问到就说"要看手上这只舵机的说明书"。
> ⚠️ 仿真版没有真 ADC 也没有真 PWM，验证的是**角度→脉宽映射**本身。

# Q6 红外避障（基础 10 + 附加 5）

**一句话**：有遮挡就蜂鸣器响+红灯，没遮挡静音+绿灯；附加用 AO 接 ADC 按反射强度分级，越近越急。

## 引脚 / 接线速查

| 功能 | 真板引脚 | 仿真版 |
|---|---|---|
| 红外 DO | PB0 | —（用 AO 阈值复刻） |
| 红外 AO | **PA1**（ADC1_IN1）⚠️需分压 | mailbox 0x2001FF00 |
| 有源蜂鸣器 | PB6（高电平响） | PE0 |
| LED 红 | PB1 | PD14 |
| LED 绿 | PB2 | PD12 |

> ⚠️ 模块 AO 常达 3~4.8V，**超 F407 的 3.3V 上限，必须分压**（1k/2k 分到 1/3）。

## 核心逻辑伪代码

```
HALF_MS = {0, 300, 150, 75}        # 每级的"响多久停多久"

循环:
    ao = 读ADC(PA1)
    if ao < 800  -> level = 0      # 无障碍
    elif ao < 1800 -> level = 1    # 远：300ms
    elif ao < 3000 -> level = 2    # 中：150ms
    else              level = 3    # 近：75ms

    if level == 0: 绿灯=1, 红灯=0, 蜂鸣器=0, alarm=0
    else:
        if !alarm: alarm=1, next_flip = millis()
        if millis() >= next_flip:              # 非阻塞
            out ^= 1                            # 翻转响/停
            红灯 = 蜂鸣器 = out;  绿灯 = 0
            next_flip = millis() + HALF_MS[level]
```

## 关键常量

| 项 | 值 |
|---|---|
| 阈值 | 800（AO_THRESHOLD） |
| 分级点 | 1800 / 3000 |
| HALF_MS | `{0, 300, 150, 75}` |
| 时基 | 毫秒计数（S真板 TIM6 / 仿真实 72000） |

## 高频追问 + 一句话答法

- **分级报警怎么做的？** → AO 分四段，每级对应一个"响多久停多久"的半周期：300/150/75ms。人耳对疏密非常敏感，越急促越觉得危险。
- **为什么用节奏不用音量/音高？** → 有源蜂鸣器自带振荡源，音高固定一千多 Hz，只能控制响/不响。要变调得换无源+Q7 那套。
- **有源 vs 无源？** → 有源内部有振荡源，给电平就响；无源没有振荡源，必须给方波，给直流反而不响。
- **AO 能直接接 ADC 吗？** → 不能。这模块 5V 供电，AO 能到 4V 多，超了 F407 的 3.3V，轻则读数不对重则烧 IO。必须分压。
- **为什么不用 delay？** → delay 会让主循环停在那儿空转。毫秒计数只判断"到没到点"，到了翻一下就走，程序行为确定且能随时收新命令。

## 被问住就说

> ⚠️ **仿真版没用 DO**，是用 AO 阈值模拟出"有没有障碍"（复刻模块内部的比较器）。真板基础题直接读 DO 即可，判定逻辑一样。
> ⚠️ **800/1800/3000 是我按模块默认电位器定的经验值，没有完整标定过**。被问到就说"要拿串口打点重新标定，不同传感器量程不一样"。

# Q3 OLED（10 分）

**一句话**：点亮 128×64 SSD1306（I2C），显示"鹅耶"和"好想加入深大电协硬件部啊"。

## 引脚 / 接线速查

| 功能 | 引脚 |
|---|---|
| I2C1_SCK | **PB6**（AF4） |
| I2C1_SDA | **PB7**（AF4） |
| 器件地址 | SSD1306 **0x3C**（实际发 `0x3C<<1 = 0x78`） |
| 调试串口 | PA9=TX / PA10=RX（AF7, 115200） |

> ⚠️ I2C 必须**开漏 + 4.7k 上拉到 3.3V**，不上拉完全不工作。

## 核心逻辑伪代码

```
oled_init():    发一串初始化命令（对比度/显示开关/页寻址方式/列范围）
oled_line(r,s): 把字符串写进 RAM 行缓冲 r，超长截断，剩余补 0
oled_refresh(): 经 I2C 把 1024 字节显存刷到屏幕

main():
    oled_init()
    oled_line(0, "")
    oled_line(1, MY_NAME)                 # ← 改这里
    oled_line(2, "好想加入深大电协硬件部啊")
    oled_line(3, "")
    oled_refresh()
```

## 关键常量

| 项 | 值 |
|---|---|
| 显存 | 8 页 × 128 列 = **1024 字节**，1 位 = 1 像素 |
| 汉字 | 16×16 点阵 = **32 字节/字**，只取用到的字 |
| I2C 速率 | 400kHz（`I2C_CCR=280`，`TRISE=17`） |
| 一帧耗时 | 1024 字节 @400kHz ≈ 25ms |

## 高频追问 + 一句话答法

- **地址为什么还要左移？** → I2C 帧发的是"地址+读写位"，所以写进 OAR1 的是 `0x3C<<1=0x78`，写错就一点反应没有。
- **I2C 为什么要上拉？** → 线与总线，器件只能拉低不能拉高（开漏），靠上拉拉高，这样两设备同时发也不打架。
- **汉字怎么显示？** → 取模软件把字转成点阵存成字库数组，写进帧缓冲对应页列，整帧刷出去。只取用到的字，不带全字库。
- **显存多大？怎么对应像素？** → 8 页 × 128 列 = 1024 字节，每位一个像素；页地址方式（0x20 水平/0x21 垂直）在初始化命令里定死。
- **等 TXE 还是 BTF？** → 必须等 **BTF**。TXE 只说明数据寄存器空了，BTF 才说明字节真的移位发完了，不等会**字节错位**。
